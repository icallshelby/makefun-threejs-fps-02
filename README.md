# SKYLINE — Tactical FPS

Original tactical FPS set on "Halcyon Roof" (rooftop twin tower at night with neon skyline).

## Controls
- **W, A, S, D**: Move
- **Mouse**: Look
- **Click**: Fire
- **R**: Reload
- **B**: Buy Menu
- **E**: Plant / Defuse Beacon
- **1 / 2**: Switch Weapons
- **M**: Mute Audio

## Running Locally
```bash
node serve.ts --port 8091
```
Open `http://localhost:8091`.
